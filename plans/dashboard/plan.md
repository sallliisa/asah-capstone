# Dashboard delivery

The dashboard combines room occupancy, tenant assessments, open work, upcoming plans, and settled cash. Use the existing reads and permissions for each. A single resource list cannot present these records together.

Keep the full room map in the occupancy section. Show operational work and the schedule before scrolling. Place cash analysis directly after the schedule. Link to full lists and assessment history at their existing destinations.

Verify the first viewport with a populated property at desktop and phone widths. Follow a room tile and a filtered cash total to their source records. Check the dates, room, and transaction amounts after each filter change. See [dashboard verification](verification.md) for results.
